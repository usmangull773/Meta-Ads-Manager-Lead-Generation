The plan

Built in order, so each step earns the next.

Measurement first, then launch, then scale. Nothing is scaled before it can be measured.

Phase 1
First 2 weeks

Get the measurement right

  • Clean up the pixels and set proper lead, appointment and sale events.
  • Add Conversions API and connect the CRM.
  • Stand up one dashboard across the brands.
Phase 2
Weeks 3 to 6

Launch and learn

  • Run cold campaigns per brand against the strongest offers.
  • Build retargeting from site visitors, video viewers and engagers.
  • Test creatives, headlines and audiences, and read lead quality, not volume.
Phase 3
Weeks 7 to 12

Scale what pays back

  • Scale the winners and cut spend on what does not convert.
  • Expand across brands using what already works.
  • Report every week in plain, revenue terms.
